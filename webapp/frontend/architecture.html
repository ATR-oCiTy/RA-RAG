Architecture & attack paths

How this tool's two-phase pipeline mirrors RA-RAG's actual estimate-then-freeze-then-infer design (Hwang et al., EMNLP 2025), and the four ways a source can exploit the gap between "agreed a lot" and "was actually trustworthy."

Phase 1 — Estimation
Sources answer calibration queries
Every source gets a query + its own context, answers independently (wrap_prompt + Gemini). No source sees another's answer.
AlignScore grounding filter
Each answer is converted to a declarative claim (QAConvertor) and scored against its own context (AlignScore-base). Ungrounded or contradicted answers become "i don't know" before they count for anything.
Reliability estimation (EM)
iterative_weighted_majority_voting repeatedly estimates a consensus answer per round and credits each source by how often it matched — this is a weighted-majority-vote crowdsourcing estimator, the same family as Dawid–Skene.
Lock
Weights freeze here. Nothing estimated after this point ever changes them again — this is the exact point a build-then-betray attacker is trying to survive until.
Phase 2 — Inference
κ-RRSS source selection
For each real query, only the top-κ sources by frozen weight are consulted at all. Lower-weight sources are excluded entirely, not just down-weighted.
Semantic clustering
The chosen sources' answers go through EntailmentDeberta (pairwise NLI) so paraphrases ("Paris" / "the capital is Paris") merge into one candidate before voting.
Weighted majority vote
weighted_majority_voting picks the answer with the highest summed frozen weight among the consulted sources. This is the final answer.

Four attack paths

All four are runnable as one-click presets in the Attack tab.

1. Build-then-betray, outnumbered

fails

One adversary behaves honestly through calibration, earning weight 1.0 — the theoretical maximum a single accuracy-based estimator can award. At the target query it defects. Two honest sources, also at 1.0 each, simply outvote it: 2.0 > 1.0. A reliability weight is capped at 1.0 by construction, so a lone adversary can never outvote two honest sources that agree with each other, no matter how much "trust" it built.

2. Colluding sybils

succeeds

Fix path 1's ceiling by adding a second adversary. Two colluding sources, both honestly agreeing through calibration, both defect together on the target query with the identical payload. Their combined weight (2.0) now exceeds the lone honest source (1.0) — the estimator has no way to tell that the two "independent" corroborating sources are in fact the same actor, because it never checks for dependence between sources at all.

3. κ-RRSS as a double-edged sword

defense holds — usually

Lowering κ to 1 with a tied-weight adversary shows the defense working as designed: a low-ranked adversary gets excluded from the vote before it ever gets a hearing — its payload is never even asked. But path 4 shows the same mechanism can backfire: if κ trims the field down to exactly the adversary plus one honest source, and that honest source's own weight has been discounted below the adversary's, the very defense meant to filter out unreliable sources hands the attacker a 1-on-1 matchup it wins outright.

4. Disagreement erosion (single adversary)

succeeds — no collusion needed

The one that doesn't need multiple sources or a weakness in κ. Three honest sources genuinely disagree with each other on disputed trivia (Bell/Meucci, Edison/Swan, Amundsen/Scott). The adversary never needs to know any answer — it just sides with whichever pair already agrees, banking a free 1.0 track record, while each honest source individually drops to 0.75 for disagreeing with a peer once. Once every individual honest source is weaker than the adversary, κ-RRSS excludes the others and hands it a win.

What this maps to in the thesis

Paths 1–2 are H1 (a patient attacker defeats the defense once enough resources/collusion are spent). Path 3 shows the defense doing its job. Path 4 is the sharper H2 finding: the estimator treats agreement as sufficient evidence of trustworthiness without ever checking whether that agreement was independently arrived at — a single adversary can free-ride on honest sources' own disagreement with each other, and the very mechanism meant to filter unreliable sources can end up assisting it.
